# Frontend — El sesgo bajo control

React + TypeScript + Vite. Renderiza las ecuaciones del modelo con KaTeX
(`react-katex`) y los resultados con Recharts. Consume la API de FastAPI en
`../backend`.

```bash
npm install
npm run dev
```

Requiere el backend corriendo (por defecto en `http://localhost:8000`,
configurable en `.env` vía `VITE_API_BASE`).

Ver el README raíz del proyecto para la explicación completa.
